# Issue #250: Complete Atlassian OAuth setup for Jira and Confluence

## Changes Made

### 1. PKCE Store Migration (Phase 3)
- Added `pkce_challenges` DB table to `schema.ts` with columns: `state`, `code_verifier`, `user_id`, `team_id`, `expires_at`
- Migrated `atlassian.service.ts` from in-memory `Map` to DB-backed PKCE storage
- `buildAuthUrl()` and `getPkceData()` are now async, reading/writing from DB
- Expired challenges are cleaned up opportunistically on each new auth request

### 2. Webhook HMAC Validation (Phase 4)
- Added `JIRA_WEBHOOK_SECRET` to `config.ts` env schema
- Implemented `validateJiraWebhookSignature()` in `atlassian.service.ts` using HMAC-SHA256
- Jira webhook route now validates signatures; rejects 401 on invalid signatures
- Gracefully skips validation when `JIRA_WEBHOOK_SECRET` is not set (dev mode)

### 3. HKDF Key Derivation (Phase 5)
- Replaced `crypto.createHash('sha256')` with `crypto.hkdfSync()` in `encryption.ts`
- Uses fixed salt (`nyx-atlassian-token-encryption`) and info string (`aes-256-gcm-key`)
- Note: existing encrypted tokens will need re-encryption on first deployment with new key derivation

### 4. Rich ADF Conversion (Phase 6)
- Extended `textToAdf()` to handle: headings (h1-h6), bullet lists, numbered lists, fenced code blocks with language
- Added `parseInlineMarks()` for: **bold**, *italic*, `inline code`, [links](url)
- Extended `adfToText()` to reverse-convert headings, code blocks, and lists back to markdown
- Added comprehensive unit tests for all new ADF node types

### 5. Automated Webhook Registration (Phase 7)
- Added `registerJiraWebhook()` and `deleteJiraWebhook()` to `atlassianService`
- OAuth callback now auto-registers a Jira webhook after successful connection
- Webhook ID stored in `atlassian_connections.webhook_id` column (new)
- On disconnect, the registered webhook is automatically cleaned up

### 6. Updated Tests
- Extended `atlassian.service.test.ts` with tests for rich ADF conversion, inline marks, webhook validation
- All 1063 tests pass across 109 test files

## Files Modified
- `apps/api/src/db/schema.ts` — added `pkceChallenges` table, `webhookId` column on `atlassianConnections`
- `apps/api/src/lib/config.ts` — added `JIRA_WEBHOOK_SECRET` env var
- `apps/api/src/lib/encryption.ts` — upgraded key derivation from SHA-256 to HKDF
- `apps/api/src/services/atlassian.service.ts` — DB-backed PKCE, rich ADF, webhook management, signature validation
- `apps/api/src/routes/integrations/atlassian.ts` — async PKCE, webhook validation, auto-register webhook on connect
- `apps/api/src/services/__tests__/atlassian.service.test.ts` — expanded test coverage

- Run `pnpm --filter api exec drizzle-kit push` to create the `pkce_challenges` table and add `webhook_id` column
- Set `JIRA_WEBHOOK_SECRET` env var in staging/production for webhook signature validation
- Existing encrypted tokens will need re-encryption due to HKDF key derivation change
