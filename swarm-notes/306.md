# Ticket #306 — CLI: Add billing portal command

## What was done
- Created `packages/cli/src/commands/billing.ts` with three subcommands
- Registered `registerBillingCommand` in `packages/cli/src/index.ts`

## Implementation details
- `nyx billing plans` — fetches `GET /api/subscriptions/plans` and renders a table with plan name, price, and features
- `nyx billing current` — fetches `GET /api/subscriptions/current?teamId=...` and displays plan, status, renewal date, and cancellation info
- `nyx billing portal` — posts to `POST /api/billing/portal` with teamId and returnUrl, displays the Stripe portal URL
- All subcommands support `--format json|table` output
- `current` and `portal` support `--team-id` option (falls back to configured team)
- `portal` supports `--return-url` option (defaults to `https://app.nyx.dev`)

## API endpoints used
- `GET /api/subscriptions/plans` (from `apps/api/src/routes/subscriptions.ts`)
- `GET /api/subscriptions/current` (from `apps/api/src/routes/subscriptions.ts`)
- `POST /api/billing/portal` (from `apps/api/src/routes/billing.ts`)

- `pnpm --filter @nyx/cli build` passes successfully
