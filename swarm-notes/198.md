# Ticket #198 — Add Otter.ai text transcription integration to intake stage

## What was done

1. **Created `apps/api/src/services/integrations/otter.service.ts`** with:
   - `importTranscript(transcriptText, existingContent)` — formats raw transcript text preserving speaker labels and timestamps, appends to document content with markdown heading and separator
   - `formatTranscriptForIntake(transcriptText)` — detects speaker label patterns (e.g. "Alice  0:00") and formats them as bold speaker names with italic timestamps
   - `listTranscripts()` — returns mock data when OTTER_API_KEY is not set; throws when live API would be called
   - `getTranscript(id)` — returns mock transcript detail by ID when OTTER_API_KEY is not set

2. **Added routes to `apps/api/src/routes/integrations.ts`**:
   - `POST /api/integrations/otter/import` — accepts `{ transcriptText, documentId }`, fetches the document, appends formatted transcript, updates document
   - `GET /api/integrations/otter/transcripts` — lists available transcripts (mock data without API key)
   - `GET /api/integrations/otter/transcripts/:id` — fetches single transcript detail

3. **Added `OTTER_API_KEY` to config schema** in `apps/api/src/lib/config.ts` as optional string

4. **Route already registered** — `integrationRoutes` was already registered in `apps/api/src/app.ts` at `/api/integrations`, so the new otter routes are automatically available

5. **Created tests** in `apps/api/src/services/__tests__/otter.service.test.ts` — 14 tests covering:
   - Speaker label detection and formatting
   - Transcript import with empty and existing content
   - Empty transcript rejection
   - Mock transcript listing and retrieval
   - Not-found error handling

## What was not done
- Live Otter.ai API integration (stubs throw when OTTER_API_KEY is set — real API client needs to be implemented when Otter provides API access)
- Auth middleware on the otter routes (the existing integrations file has mixed auth — some routes use requireRole, others don't)

## Environment setup needed
- If connecting to a real Otter.ai account: set `OTTER_API_KEY` environment variable in Railway/Vercel
