# Ticket #283 — Review and tune API rate limits

## Changes

### `apps/api/src/app.ts`
- Raised global rate limit from 100 to 200 req/min
- Added `allowList` callback to exempt `/health` and `/api/webhooks/` routes from rate limiting

### `apps/api/src/routes/ai.ts`
- Added `config.rateLimit` (20 req/min) to 5 AI endpoints that were missing it:
  - `/meeting-quality`
  - `/meeting-apply-suggestions`
  - `/seed-from-stage`
  - `/missing-sections`
  - `/notification-reply`
  - `/decision-weight`
- All other AI endpoints already had the 20 req/min override; no changes needed there

### `apps/api/src/routes/agent.ts`
- Added 5 req/min rate limit on agent session creation (`POST /`)

### `apps/api/src/routes/upload.ts`
- Added 10 req/min rate limit on file upload (`POST /:id/upload`)

## Type check
- `tsc --noEmit` passes for all modified files
- Pre-existing errors in unrelated files (voice services, `@nyx/shared` module resolution) are not affected by these changes
