# Ticket #270 — AI agent output lacks line breaks between sentences/messages

## Changes

### `apps/web/src/components/MarkdownPreview.tsx`
- Added Tailwind typography spacing utilities to the prose container: `prose-p:my-3`, `prose-headings:mt-4`, `prose-headings:mb-2`, `prose-ul:my-2`, `prose-ol:my-2`, `prose-li:my-0.5`
- These ensure paragraphs, headings, lists, and list items have proper vertical spacing in AI-rendered markdown

### `apps/web/src/components/UnifiedAIPanel.tsx`
- Removed `text-xs` from three wrapper elements (user message `<p>`, AI message `<div>`, and streaming content `<div>`)
- The `text-xs` class was conflicting with the prose container's `text-sm`, causing inconsistent sizing and compressed spacing

## Verification
- TypeScript type check passes (`tsc --noEmit`)
