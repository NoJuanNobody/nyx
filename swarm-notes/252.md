# Ticket #252 - Restrict CORS to trusted origins only

## Changes

1. **`apps/api/src/lib/config.ts`** - Added `CORS_ORIGINS` (optional string) to the Zod env schema.
2. **`apps/api/src/app.ts`** - Replaced `origin: true` (allow-all) with a callback that checks the request origin against an allowlist parsed from `CORS_ORIGINS`. Defaults to `['http://localhost:5173']` when unset. Requests with no origin header (e.g., server-to-server) are allowed through.
3. **`.env.example`** - Added `CORS_ORIGINS=http://localhost:5173` with documentation.

## Testing

All 1047 unit tests pass (109 test files, 5 workspaces).

## Deployment notes

Set `CORS_ORIGINS` in each environment:
- **Staging:** `CORS_ORIGINS=https://staging.nyx.dev,http://localhost:5173`
- **Production:** `CORS_ORIGINS=https://app.nyx.dev`
