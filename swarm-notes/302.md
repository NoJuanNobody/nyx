# Ticket #302 -- CLI: Extend export to all formats

## Changes

### `packages/cli/src/client.ts`
- Added `postRaw()` method to `NyxClient` for POST endpoints that return raw responses (needed by latex and jupyter export endpoints).

### `packages/cli/src/commands/deliverables.ts`
- Extended `deliverables export` command to support `latex` and `jupyter` formats (in addition to existing markdown, pdf, txt, docx).
- Added `--theme` option for LaTeX exports.
- LaTeX and Jupyter use POST requests; other formats continue using GET.

### `packages/cli/src/commands/bulk.ts`
- Extended `bulk export` command to support all six formats: markdown, pdf, txt, docx, latex, jupyter.
- Added `--theme` option for LaTeX exports.
- Added format validation with clear error messages.
- Refactored extension mapping and binary/text detection to use lookup tables instead of conditionals.

## API Endpoints Used
- GET `/api/export/documents/:id/export/markdown`
- GET `/api/export/documents/:id/export/pdf`
- GET `/api/export/documents/:id/export/txt`
- GET `/api/export/documents/:id/export/docx`
- POST `/api/export/documents/:id/export/latex` (body: `{ theme }`)
- POST `/api/export/documents/:id/export/jupyter` (body: `{}`)
