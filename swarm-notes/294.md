# Ticket #294 — CLI: Add search and context-matching commands

## Changes
- Created `packages/cli/src/commands/search.ts` with two commands:
  - `nyx search <query>` — POSTs to `/api/search` with `{ query }`, displays results in table or JSON
  - `nyx context <doc-id>` — Fetches document content, then POSTs to `/api/intake/context` with `{ rawInput, teamId }`, displays related specs and signals
- Registered both commands (`registerSearchCommand`, `registerContextCommand`) in `packages/cli/src/index.ts`

## API routes used
- `POST /api/search` — web search (defined in `apps/api/src/routes/search.ts`)
- `POST /api/intake/context` — context matching (defined in `apps/api/src/routes/context.ts`, mounted under `/api/intake`)
- `GET /api/documents/:id` — fetch document content before context matching

- TypeScript compilation passes with zero errors
