# Ticket #304 — CLI: Add credits and usage commands

## What was done

1. **Created CLI command** (`packages/cli/src/commands/credits.ts`):
   - `nyx credits balance` — fetches and displays current credit balance from `GET /api/credits/balance`
   - `nyx credits usage` — shows credit cost breakdown per task type from `GET /api/credits/costs`, rendered as a table with human-readable task names
   - `nyx credits history` — lists credit transactions from `GET /api/credits/transactions` in a table with columns: When (timeAgo), Type, Amount (+/-), Description. Supports `--limit` option (default 20)
   - All subcommands support `--format json|table` output

2. **Registered in CLI entry point** (`packages/cli/src/index.ts`).

## API endpoints used

- `GET /api/credits/balance` — returns `{ balance: number }`
- `GET /api/credits/costs` — returns `{ costs: Record<string, number> }`
- `GET /api/credits/transactions?limit=N` — returns `{ transactions: [...] }`

## Build result

`pnpm --filter @nyx/cli build` passes with no errors.
