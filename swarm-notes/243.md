# Ticket #243: Fix board tickets not updating status from In Progress to Completed

## Root Causes

### 1. No manual status update endpoint (API)
There was no PATCH endpoint for ticket status. The only way to change status was via `syncStatus` (polling external providers) or `syncAllForTeam`. Users had no way to manually move tickets between columns.

### 2. No manual status change UI (Frontend)
The Board component rendered tickets as read-only cards with no mechanism to change status. Added a status dropdown on each ticket card that triggers a mutation and invalidates the board query.

### 3. GitHub webhook missing `issues` event handler
The webhook route only handled `push` and `issue_comment` events. When a GitHub issue was closed or reopened, the board was never updated. Added an `issues` event handler that maps `closed`/`reopened`/`opened` actions to the correct ticket status.

### 4. Missing `updateTicketStatus` frontend API function
No function existed to call the status update endpoint from the frontend. Added `updateTicketStatus()` to `api.ts`.
