# Ticket #240: Context menu 'Suggest Tickets' opens BulkTicketReview modal

## Problem
The "Generate ticket suggestions" right-click option on folders in the file tree
rendered an inline panel (`absolute inset-0 z-30`) that completely covered the
explorer, displacing the file tree.

## Solution
Replaced the inline panel with the existing `BulkTicketReview` modal component.

### Changes

**`apps/web/src/components/FileTree.tsx`**
- Removed all inline suggestion panel state: `folderSuggestions`,
  `folderSuggestionsLoading`, `approvingIds`, `approvedIds`, `dismissedIds`,
  `bulkApproving`, `approveError`.
- Removed handler functions: `handleGenerateFolderSuggestions`,
  `handleApproveSuggestion`, `handleDismissSuggestion`, `handleApproveAll`.
- Removed the inline loading overlay and suggestions panel (~130 lines of JSX).
- Added `bulkTicketFolderPath` state — when set, renders `<BulkTicketReview>` as
  a modal with the `folderPath` prop.
- Context menu action now calls `setBulkTicketFolderPath(path)` instead of
  `handleGenerateFolderSuggestions(path)`.
- Removed unused imports (`generateFolderTicketSuggestions`,
  `bulkApproveSuggestions`, `dismissTicketSuggestion`, `TicketSuggestion`).

**`apps/web/src/components/BulkTicketReview.tsx`**
- Added optional `folderPath` prop to `BulkTicketReviewProps`.
- When `folderPath` is provided, the generate mutation calls
  `generateFolderTicketSuggestions(teamId, folderPath)` instead of
  `generateBulkSuggestions(documentId)`.
- Added `generateFolderTicketSuggestions` to imports from `../lib/api`.

## Testing
All 984 unit tests pass (103 test files, 5 workspaces).
