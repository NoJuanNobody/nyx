# Ticket #152 — Quality Scoring and Auto-Apply Flow for Meeting Notes

## Changes

1. **`apps/api/src/services/ai.service.ts`** — Added two new methods:
   - `analyzeMeetingNoteQuality(content)` — meeting-specific quality analysis returning score (1-10), suggestions, and meetingMetrics (decisions, actionItems, codeReferences, openQuestions)
   - `applyMeetingSuggestions(content, suggestions)` — sends content + suggestions to AI and returns improved content

2. **`apps/api/src/routes/ai.ts`** — Added two new endpoints:
   - `POST /api/ai/meeting-quality` — accepts `{ content }`, returns quality analysis
   - `POST /api/ai/meeting-apply-suggestions` — accepts `{ content, suggestions }`, returns `{ content }` with improvements applied

3. **`apps/web/src/lib/api.ts`** — Added API client functions:
   - `analyzeMeetingQuality(content)` — calls meeting-quality endpoint
   - `applyMeetingSuggestions(content, suggestions)` — calls meeting-apply-suggestions endpoint
   - Exported `MeetingQualityResult` and `MeetingMetrics` interfaces

4. **`apps/web/src/components/MeetingAutoApply.tsx`** (new) — Auto-apply component:
   - Checkbox-based suggestion selection with Select All / Deselect All
   - Per-suggestion Accept (checkmark) / Reject (X) buttons
   - Apply Selected button with loading state
   - Follows BulkTicketReview multi-select pattern

5. **`apps/web/src/components/MeetingNoteQuality.tsx`** (new) — Meeting quality panel:
   - Score ring SVG (reused pattern from AIQualityPanel)
   - Meeting metrics grid (decisions, action items, code refs, open questions)
   - Suggestion list with MeetingAutoApply for granular selection
   - "Fix All" button for one-click apply
   - 500ms debounced analysis
   - Re-fetches quality after suggestions are applied
   - Success feedback banner

6. **`apps/web/src/pages/DocumentEditor.tsx`** — Added MeetingNoteQuality panel:
   - Detects meeting-sourced documents via `content.trimStart().startsWith('# Meeting Notes:')`
   - Renders MeetingNoteQuality below AIAdvisor when detected
   - onApply callback updates document content and triggers save

7. **`apps/api/src/services/__tests__/meeting-quality.test.ts`** (new) — 8 unit tests:
   - Quality analysis with valid JSON response
   - Code fence stripping
   - Fallback for non-JSON responses
   - Default values for missing meetingMetrics fields
   - Suggestion application returning improved content
   - Code fence stripping on apply response
   - All suggestions included in prompt
   - Score recalculation after edits

## Design Notes

- The meeting quality criteria are embedded in the AI prompt (not hardcoded scoring logic), keeping the system provider-agnostic per governance rules.
- The `analyzeMeetingNoteQuality` method follows the same JSON extraction + fallback pattern as `analyzeSpecQuality`.
- Meeting detection in DocumentEditor uses a simple content prefix check (`# Meeting Notes:`) which aligns with the doc-transformer service output format.
