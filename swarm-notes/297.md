# Ticket #297 — CLI: Add snapshot and timeline commands

## What was done

- Created `packages/cli/src/commands/timeline.ts` with `nyx timeline <doc-id>` command
  - Calls GET `/api/documents/:documentId/timeline`
  - Table output with event type, actor, metadata, and relative timestamp
  - Supports `--format json|table`

- Created `packages/cli/src/commands/snapshot.ts` with subcommands:
  - `nyx snapshot list` — GET `/api/snapshots` (supports `--team-id`)
  - `nyx snapshot create --name <name> --doc-ids <ids>` — POST `/api/snapshots`
  - `nyx snapshot get <id>` — GET `/api/snapshots/:id`
  - `nyx snapshot restore <id>` — POST `/api/snapshots/:id/restore`

- Registered both commands in `packages/cli/src/index.ts`

## Verification

- `pnpm --filter @nyx/cli build` passes successfully
