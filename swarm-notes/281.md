# Ticket #281 — PostgreSQL automated backups

## What was done
- Created `.github/workflows/db-backup.yml` with:
  - Daily schedule at 3 AM UTC via cron
  - `workflow_dispatch` trigger for manual runs
  - PostgreSQL client installation step
  - `pg_dump` using `DATABASE_PUBLIC_URL` secret (custom format, no owner/privileges for portability)
  - Verification that the dump file is non-empty
  - Upload as GitHub artifact with 30-day retention

## Style conventions followed
- `ubuntu-latest` runner (matches ci.yml)
- `actions/upload-artifact@v4` (v4 consistent with checkout@v4 used elsewhere)
- Step naming style matches existing workflows

## Manual steps required
- The `DATABASE_PUBLIC_URL` secret must be configured in GitHub repository settings (Settings > Secrets and variables > Actions). This should be the publicly-routable PostgreSQL connection string from Railway.
