# Ticket #274 -- Stripe billing code gaps

## Changes made

### 1. Added 3 missing webhook handlers (`apps/api/src/services/stripe.service.ts`)
- `customer.subscription.created`: Upserts subscription record and stripe_customers when a new subscription is created directly (not via Checkout).
- `invoice.paid`: Marks subscription as `active` when an invoice is successfully paid (handles renewal payments).
- `invoice.payment_failed`: Marks subscription as `past_due` when payment fails.
- Used Stripe v20 API (`invoice.parent.subscription_details.subscription`) instead of deprecated `invoice.subscription`.

### 2. Registered `fastify-raw-body` plugin (`apps/api/src/app.ts`)
- Added `fastify-raw-body` as a dependency (the `@fastify/raw-body` scoped package does not exist on npm).
- Registered the plugin with `global: false` and `runFirst: true` so routes that set `config.rawBody: true` (billing and subscription webhook routes) get access to the raw request body for Stripe signature verification.

### 3. Documented credit purchase Stripe gap (`apps/api/src/routes/credits.ts`)
- Added TODO comment on the `/purchase` endpoint noting it currently bypasses Stripe and needs Checkout integration.

### 4. Added missing env vars to `.env.example`
- Added `STRIPE_PRICE_PRO`, `STRIPE_PRICE_TEAM`, `STRIPE_PRICE_ENTERPRISE` with descriptions.
