# 246 — Fix credits not decrementing when AI agents consume compute

## Problem
The credit balance was never deducted when AI agent workflows ran. `credits.service.ts` had `deductCredits` and `getBalance`, but `agent/loop.ts` never called them.

## Changes

### `apps/api/src/services/credits.service.ts`
- Added per-workflow credit costs (`agent_full_spec_review: 5`, `agent_change_impact_analysis: 4`, etc.) plus `agent_custom: 3` as fallback.
- Added `getAgentCost(workflowId?)` helper that maps a workflow ID to its credit cost.
- Added `checkCredits(userId, required)` pre-flight check that returns `{ allowed, balance, required }`.

### `apps/api/src/services/agent/loop.ts`
- Imported `checkCredits`, `deductCredits`, `getAgentCost` from credits service.
- Added `workflowId` to `AgentLoopOptions`.
- **Before the loop starts**: calls `checkCredits` — if insufficient, sets session to `failed`, emits `credits_depleted` event, throws 402.
- **After successful completion** (both normal and max-iterations): calls `deductCredits` with the workflow cost. The new `done` event includes `creditsUsed` and `creditBalance`.

### `apps/api/src/services/agent/types.ts`
- Added `credits_depleted` event type with `balance` and `required` fields.
- Added optional `creditsUsed` and `creditBalance` to the `done` event.

### `apps/api/src/routes/agent.ts`
- Passes `workflowId` through to `runAgentLoop`.

### `apps/web/src/lib/agent-stream.ts`
- Updated `AgentStreamEvent` union to include `credits_depleted` and the new `done` fields.

### `apps/web/src/components/UnifiedAIPanel.tsx`
- Added `useQueryClient` to invalidate `credits-balance` query after `done` events (so the sidebar updates immediately).
- Added `credits_depleted` event handler that shows an insufficient-credits message.

### `apps/api/src/services/__tests__/credits.service.test.ts`
- Updated `CREDIT_COSTS` assertion to include new agent workflow costs.
- Added tests for `getAgentCost` (known workflow, unknown workflow, undefined).
- Added tests for `checkCredits` (sufficient, insufficient, zero balance, exact match).
