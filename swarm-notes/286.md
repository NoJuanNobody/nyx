# 286 — Document chunking & embedding pipeline

## What was done
- Created `apps/api/src/services/chunking.service.ts` — splits document text into ~2000-char chunks with 200-char overlap, splitting on paragraph then sentence boundaries
- Created `apps/api/src/services/embedding.service.ts` — generates embeddings via OpenAI `text-embedding-3-small` (1536 dims), matching the `doc_chunks` table schema
- Created `apps/api/src/services/embedding-pipeline.service.ts` — orchestrates chunk + embed + store in a transaction (delete old chunks, insert new ones)
- Wired pipeline into `apps/api/src/routes/documents.ts`:
  - POST (create): fire-and-forget `indexDocument` after insert
  - PUT (update): fire-and-forget `indexDocument` when content changes
  - DELETE (archive): fire-and-forget `removeDocumentChunks`

## Design decisions
- Gracefully skips indexing when `OPENAI_API_KEY` is not configured (no error thrown)
- Uses `setImmediate` for fire-and-forget to avoid blocking API responses
- Version field uses epoch seconds from `updatedAt` timestamp for updates, `1` for creates
- Batch embedding: sends all chunks in a single OpenAI API call
