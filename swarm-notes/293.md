# Ticket #293 - CLI: Add ticket commands (list, create, sync)

## What was done
Extended `packages/cli/src/commands/tickets.ts` with four new subcommands:

1. **`nyx tickets list-all`** - Lists all team tickets via `GET /api/tickets?teamId=...` with table output (ID, Title, Status, Provider, Created columns). Supports `--team-id` and `--format json|table`.

2. **`nyx tickets create <doc-id>`** - Creates a ticket from a document via `POST /api/documents/:id/tickets`. Requires `--provider` and `--title`, optional `--body`. Supports `--format json|readable`.

3. **`nyx tickets sync`** - Syncs all team tickets with external providers via `POST /api/tickets/sync-all?teamId=...`. Reports synced/error counts. Supports `--team-id` and `--format json|readable`.

4. **`nyx tickets status <ticket-id>`** - Updates ticket status via `PATCH /api/tickets/:id/status`. Requires `--status` (open|in_progress|closed). Validates status before sending. Supports `--format json|readable`.

## Patterns followed
- Used `resolveTeamId()` for team-scoped commands (list-all, sync)
- Used `formatTable()` for table output in list-all
- Used `formatOutput()` for JSON output
- Used `error()` helper for error handling
- Added `Ticket` interface for typed responses
- Matched existing option conventions (--format, --team-id)
