# Ticket #235: Allow maximum score of 10/10 in AI Advisor doc quality scoring

## Changes

**File:** `apps/api/src/services/ai.service.ts` (lines 128-129 of the `analyzeSpecQuality` system prompt)

### What changed

The AI Advisor's system prompt for `analyzeSpecQuality` was updated to:

1. Explicitly state that 10/10 is achievable and should be awarded when warranted
2. Add a full scoring rubric (1-3, 4-6, 7-8, 9, 10) with clear criteria at each tier
3. Define what distinguishes a 9 (excellent, trivial polish remaining) from a 10 (exceptional, no meaningful improvements needed)
4. Include an explicit instruction: "Do not withhold a perfect score simply because 'there is always room for improvement'"

### Why

The previous prompt said "rate its quality from 1 to 10" without any guidance on what each score means. LLMs tend to avoid giving perfect scores unless explicitly told it's acceptable. This change removes that implicit bias and provides clear, objective criteria for the full scoring range.
