- Assigned `sortOrder: 2` (two templates already existed at sortOrder 0 and 1)

## Template content
The Recording Session Log template covers:
- Session details (date, location, director, times)
- Session schedule table with segment/scene planning
- Technical setup: camera configuration, audio configuration, lighting setup
- Pre-recording checklist (white balance, audio levels, release forms, media cards, timecode sync, etc.)
- Session log table for take/clip tracking with timecodes and usability ratings
- Session notes (what went well, issues encountered, unplanned moments)
- Storage & backup tracking with media card/drive inventory and backup protocol
- End-of-session summary
