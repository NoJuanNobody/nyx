# Ticket #305 — CLI: Add agent registry management commands

## What was done

- Created `packages/cli/src/commands/registry.ts` with three subcommands:
  - `nyx registry list` — lists all registered agents in a table (with `--format json` option)
  - `nyx registry get <agent-id>` — shows details for a specific agent
  - `nyx registry register --name "..." --url "..."` — registers a new agent (also accepts `--type`, `--description`, `--capabilities`)
- Registered the new command in `packages/cli/src/index.ts`
- Added a POST route to `apps/api/src/routes/agent-registry.ts` to support agent registration via the API (the service-layer `registerAgent` function already existed but had no HTTP endpoint)

## Patterns followed

- Matches existing CLI command structure (commander subcommands, NyxClient, formatTable/formatOutput, error helper)
- Follows the same option conventions (`--format`, `--team-id`) seen in `agent.ts`, `status.ts`, etc.
- API route follows the existing Fastify plugin pattern in `agent-registry.ts`
