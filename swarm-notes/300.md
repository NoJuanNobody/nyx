# Ticket #300 -- CLI: Add integration management commands

## Changes
- Created `packages/cli/src/commands/integrations.ts` with three subcommands:
  - `nyx integrations list` -- lists connected integrations in table or JSON format (calls `GET /api/integrations?teamId=X`)
  - `nyx integrations connect <provider>` -- prints OAuth URL for git providers (github/gitlab/bitbucket) or credential instructions for Jira/Confluence
  - `nyx integrations remove <provider>` -- finds integration by provider type, then deletes it via `DELETE /api/integrations/:id`
- Registered `registerIntegrationsCommand` in `packages/cli/src/index.ts`

## Supported providers
github, gitlab, bitbucket, jira, confluence

## API endpoints used
- `GET /api/integrations?teamId=X` -- list integrations
- `GET /api/integrations/<provider>/connect?teamId=X` -- OAuth connect (URL printed for browser)
- `DELETE /api/integrations/:id` -- remove integration
