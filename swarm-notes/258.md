# Ticket #258: Sanitize dangerouslySetInnerHTML in MarkdownPreview

## Changes

- Installed `dompurify` (runtime) and `@types/dompurify` (dev) in `@nyx/web`
- Added `import DOMPurify from 'dompurify'` to `MarkdownPreview.tsx`
- Wrapped the `dangerouslySetInnerHTML` value at line 67 with `DOMPurify.sanitize()`, restricting output to:
  - **ALLOWED_TAGS:** `pre`, `code`, `span`, `div`, `br`
  - **ALLOWED_ATTR:** `class`, `style`

## Why

The Shiki syntax highlighter produces HTML that is inserted via `dangerouslySetInnerHTML`. Without sanitization, any unexpected or malicious content in the highlighted output could lead to XSS. DOMPurify strips everything except the tags and attributes needed for code highlighting.

## Test Results

All 72 unit tests pass. No regressions.
