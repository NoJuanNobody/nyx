# Ticket #301 — CLI: Add AI key management (BYOK) commands

## What was done

1. **Created CLI command** (`packages/cli/src/commands/byok.ts`):
   - `nyx byok set --provider <provider> --key <key>` — sets a BYOK API key via POST `/api/teams/:id/ai-key`
   - `nyx byok status` — shows current BYOK key status via GET `/api/teams/:id/ai-key`
   - `nyx byok remove` — removes the BYOK key via DELETE `/api/teams/:id/ai-key`
   - All subcommands support `--team-id` and `--format json` options
   - Follows existing CLI patterns: uses `NyxClient`, `resolveTeamId`, `formatOutput`, `error`

2. **Registered in CLI entry point** (`packages/cli/src/index.ts`).

## API endpoints used

All endpoints from `apps/api/src/routes/ai-keys.ts`:
- `POST /api/teams/:id/ai-key` — store encrypted BYOK key (requires admin role, Team/Enterprise plan)
- `GET /api/teams/:id/ai-key` — get key status (never exposes the key itself)
- `DELETE /api/teams/:id/ai-key` — remove key and revert to Nyx-managed AI

## Notes

- The DELETE endpoint returns 204 No Content; the `remove` command handles the empty-body JSON parse gracefully.
- Key is never displayed — only the last 4 characters (suffix) are shown, matching the API behavior.
