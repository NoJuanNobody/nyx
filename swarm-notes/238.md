# Ticket #238: Ticket Suggestion Detail Drawer

## What was done
- Created `TicketSuggestionDetail.tsx` — a right-side sliding drawer that renders the full ticket suggestion content with markdown preview
- Updated `BulkTicketReview.tsx` to open the detail drawer on row click instead of the old inline expand/edit UX

## Key decisions
- Used the DocDrawer visual pattern (right-side panel with header, scrollable content, footer actions) but as a standalone component since it lives inside the BulkTicketReview modal rather than the document editor
- The drawer renders inside the modal with a flex layout so the suggestion list stays visible alongside the detail panel
- Reused the existing `MarkdownPreview` component for rendering structured description content (## Context, ## Affected Areas, ## Acceptance Criteria sections)
- Removed the old `editingId`, `expandedId`, `editTitle`, `editDescription` state and the confusing inline expand/edit pattern
- Edit mode in the drawer uses a textarea with monospace font for raw markdown editing
- Single-ticket "Create Ticket" from the drawer uses `bulkApproveMutation` with a single-item set

## Files changed
- `apps/web/src/components/TicketSuggestionDetail.tsx` (new)
- `apps/web/src/components/BulkTicketReview.tsx` (modified)
