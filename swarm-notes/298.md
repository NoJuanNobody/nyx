# Ticket #298 — CLI: Add notification management commands

## Changes
- Created `packages/cli/src/commands/notifications.ts` with five subcommands:
  - `nyx notifications list` — GET `/api/notifications` with filters (read, event-type, limit, cursor) and table output
  - `nyx notifications read <id>` — PATCH `/api/notifications/:id/read` to mark single notification as read
  - `nyx notifications read-all` — PATCH `/api/notifications/read-all` to mark all as read
  - `nyx notifications preferences` — GET `/api/notifications/preferences` with table output
  - `nyx notifications set <eventType>` — PATCH `/api/notifications/preferences/:event_type` to update preference flags
- Registered `registerNotificationsCommand` in `packages/cli/src/index.ts`

## API endpoints used
All endpoints from `apps/api/src/routes/notifications.ts`, registered at prefix `/api/notifications`.

## Build
`pnpm --filter @nyx/cli build` passes.
