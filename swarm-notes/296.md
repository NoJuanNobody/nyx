# Ticket #296 — CLI: Add deliverables commands (generate, list)

## What was done

1. **Created CLI command** (`packages/cli/src/commands/deliverables.ts`) with three subcommands:
   - `nyx deliverables generate <doc-id> --type <pdf|markdown|report> --stage <stage>` — POST to `/api/documents/:id/deliverables` to generate a deliverable
   - `nyx deliverables list <doc-id>` — GET `/api/documents/:id/deliverables` to list deliverables in table format (columns: Type, Stage, Status, Created, ID)
   - `nyx deliverables export <doc-id> --format <markdown|pdf|txt|docx>` — GET `/api/export/documents/:id/export/:format` to download and save the exported file locally

2. **Registered in CLI entry point** (`packages/cli/src/index.ts`) — added import and registration call.

3. **Export implementation** follows the existing `bulk export` pattern: uses `getRaw()` for streaming, reads `Content-Disposition` header for filename, handles binary formats (pdf/docx) via `arrayBuffer()` and text formats via `text()`.

## Build result

`pnpm --filter @nyx/cli build` passes with no errors.
