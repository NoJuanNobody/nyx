# Ticket #312 — Interactive CLI REPL mode (nyx chat)

## What was done
- Created `packages/cli/src/commands/chat.ts` with interactive REPL
- Registered `registerChatCommand` in `packages/cli/src/index.ts`

## Implementation details
- `nyx chat` starts an interactive REPL with `nyx> ` prompt using Node's `readline` module
- User input is sent via `POST /api/agent` with `Accept: text/event-stream` header
- SSE responses are streamed token-by-token to stdout; non-SSE JSON responses are also handled
- `--doc-id <id>` scopes the conversation to a specific document (sent in request body)
- `--team-id <id>` scopes the conversation to a specific team (sent in request body)
- `/quit` command and Ctrl+C (readline close) both exit cleanly with "Goodbye." message
- Empty input lines are ignored and re-prompt immediately
- Uses existing `getBaseUrl` from `lib/api.ts` and `NYX_API_KEY` env var for auth

## Build verification
- `pnpm --filter @nyx/cli build` passes with no errors
