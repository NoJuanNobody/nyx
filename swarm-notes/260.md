# Ticket #260: Require webhook signature verification in all environments

## What changed
Removed the non-production bypass in `apps/api/src/routes/webhooks.ts` (lines 78-84). Previously, when webhook signature verification failed in non-production environments, the request was allowed through with only a warning log. Now, all environments return 401 with a descriptive error message instructing the user to set `GITHUB_WEBHOOK_SECRET` or configure per-integration webhook secrets.

## Files modified
- `apps/api/src/routes/webhooks.ts` — replaced environment-conditional block with unconditional 401 response

## Testing
All 1047 unit tests pass (109 test files). The existing webhook tests already had `GITHUB_WEBHOOK_SECRET` configured in the test mock (`apps/api/src/__tests__/helpers/setup.ts`), so no test changes were needed.

## Risk assessment
Low risk. The only behavioral change is that non-production environments without a webhook secret configured will now receive 401 errors instead of silently processing unverified webhooks. Any dev/staging environment using GitHub webhooks must now have `GITHUB_WEBHOOK_SECRET` set (or per-integration secrets configured).
