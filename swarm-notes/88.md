# Ticket #88 — Audio upload + transcript ingestion

## What was built

### Backend
- **`apps/api/src/services/transcription.service.ts`** — New service with three methods:
  - `validateAudioFile()` — validates extension (.mp3, .wav, .m4a, .webm), MIME type, and size (25MB max)
  - `transcribeAudio()` — sends audio to Claude API using `input_audio` content block, returns transcript
  - `structureTranscript()` — sends transcript to Claude API to produce structured spec (title + markdown content)

- **`apps/api/src/routes/audio.ts`** — Two new endpoints registered under `/api/intake`:
  - `POST /api/intake/audio` — multipart file upload, transcribes then structures
  - `POST /api/intake/transcript` — accepts pasted transcript text, structures it
  - Uses `@fastify/multipart` (newly added dependency)

- **`apps/api/src/app.ts`** — Registered `audioRoutes` at prefix `/api/intake`

### Frontend
- **`apps/web/src/pages/IntakePage.tsx`** — Full intake page with:
  - Tab UI switching between "Upload Audio" and "Paste Transcript"
  - Drag-and-drop / file picker for audio files
  - Upload progress indicator
  - Editable transcript with re-process capability
  - Structured spec preview
  - "Create Document from Spec" button that creates a document and navigates to editor

- **`apps/web/src/lib/api.ts`** — Added `uploadAudioForIntake()` (FormData upload) and `processTranscriptForIntake()` functions

- **`apps/web/src/App.tsx`** — Added `/intake` route
- **`apps/web/src/components/Sidebar.tsx`** — Added "Audio Intake" nav link with microphone icon

### Tests
- **`apps/api/src/__tests__/services/transcription.service.test.ts`** — 12 tests covering validation, transcription, and structuring
- **`apps/api/src/__tests__/routes/audio.test.ts`** — 7 tests covering both endpoints (success, validation errors, transcription failure, structuring fallback)
- **`apps/web/src/__tests__/components/IntakePage.test.tsx`** — 7 tests covering tab switching, paste processing, error display, document creation, re-processing, and file input validation

All 362 tests pass (331 API + 31 web).

## Notes
- Added `@fastify/multipart` as a new dependency to `apps/api`
- Claude API audio transcription uses `input_audio` content blocks with base64-encoded audio
- If transcription fails, the endpoint returns a 422 with a suggestion to paste the transcript manually
- If structuring fails after successful transcription, the raw transcript is returned as fallback content
