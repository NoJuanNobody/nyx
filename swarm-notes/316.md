# Ticket #316 — Slash commands in CLI REPL

## What was done

Created `packages/cli/src/commands/slash.ts` with a slash command registry and handler for the CLI REPL.

### Exported API

- `handleSlashCommand(input: string, client: NyxClient, teamId: string): Promise<string>` — parses and dispatches a slash command, returning output for the REPL to display.
- `isSlashCommand(input: string): boolean` — helper to detect whether input is a slash command.

### Built-in commands

| Command             | Description                                |
|---------------------|--------------------------------------------|
| `/help`             | Lists all available slash commands         |
| `/docs`             | Lists documents for the current team       |
| `/quality <doc-id>` | Runs AI quality analysis on a document     |
| `/intake <text>`    | Transforms raw text into a structured spec |
| `/status`           | Checks Nyx platform health                 |
| `/quit`             | Returns `__QUIT__` sentinel for REPL exit  |

### Design notes

- Not registered as a standalone CLI command — purely a utility for the chat REPL.
- `/quit` returns the sentinel string `__QUIT__` so the REPL loop can detect it and exit gracefully.
- Unknown commands return a helpful error with a hint to use `/help`.
- All API errors are caught and returned as `Error: <message>` strings rather than throwing.
- The command registry uses a `Map` for O(1) lookup.
