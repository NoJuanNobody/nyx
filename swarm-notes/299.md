# Ticket #299 — CLI: Add API key management commands

## Changes
- Created `packages/cli/src/commands/apikeys.ts` with three subcommands:
  - `nyx apikeys list` — GET `/api/api-keys?teamId=...` with table output (ID, name, prefix, scopes, status, last used, created)
  - `nyx apikeys create --name "..."` — POST `/api/api-keys` to create a new key; displays full key once with save warning
  - `nyx apikeys revoke <key-id>` — DELETE `/api/api-keys/:keyId` to revoke a key
- Registered `registerApikeysCommand` in `packages/cli/src/index.ts`
- All subcommands support `--format json|table` and `--team-id` where applicable

## API endpoints used
All endpoints from `apps/api/src/routes/api-keys.ts`, registered at prefix `/api/api-keys`.

## Build
`pnpm --filter @nyx/cli build` passes.
