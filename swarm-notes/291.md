# Ticket #291 — CLI: Add AI generation commands

## What was done
- Created `packages/cli/src/commands/ai.ts` with four subcommands:
  - `nyx ai generate --prompt "..."` — POST `/api/ai/generate-document`
  - `nyx ai edit <doc-id> --instruction "..."` — POST `/api/ai/edit-document` (fetches doc content first)
  - `nyx ai drift <doc-id> --code <file>` — POST `/api/ai/detect-drift` (reads local file + fetches doc)
  - `nyx ai missing-sections <doc-id>` — POST `/api/ai/missing-sections` (fetches doc content + stage)
- Registered `registerAiCommand` in `packages/cli/src/index.ts`
- All commands follow existing patterns: `NyxClient`, `error()` helper, `formatOutput()`, `--format` option, stderr for progress, stdout for results
- `drift` command exits with code 1 when drift is detected (CI-friendly)
- `edit` command supports `--apply` flag to write changes back to the document

## Build verification
- `tsc` compiles with zero errors
- `dist/commands/ai.js` emitted successfully
