# 237 — Add 'Manage Repos' button to repositories page

## What was done
- Added a "Manage Repos" button to the Repositories page header area, visible whenever a GitHub integration is connected
- Button appears in both the empty-repos state and the populated-repos state
- Clicking the button opens the existing `RepoPickerModal` component, which allows users to add, remove, and configure which repos are synced
- On modal close, synced-repos and integrations queries are invalidated to refresh the list
- Button uses the specified styling: `bg-blue-600 hover:bg-blue-700 text-white rounded-lg px-4 py-2`
- Added `data-testid="manage-repos-button"` for test targeting
- Updated `e2e/fixtures/selectors.ts` with the new `manageReposButton` selector

## Tests added
- **Unit tests** (`apps/web/src/__tests__/components/Repositories.test.tsx`): 4 tests covering button rendering, styling, modal open, and modal close
- **E2E tests** (`e2e/repositories.spec.ts`): 2 tests — button visibility (237.1) and modal opening on click (237.2)

## Files changed
- `apps/web/src/pages/Repositories.tsx` — added RepoPickerModal import, showManageModal state, Manage Repos button in header areas, modal rendering
