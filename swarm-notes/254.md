# Ticket #254: Upgrade encryption key derivation from SHA-256 to HKDF

## Changes

### `apps/api/src/lib/encryption.ts`
- Replaced `createHash('sha256')` with `hkdfSync('sha256', secret, 'nyx-salt', 'nyx-integration-encryption', 32)` in `getKey()`
- Import changed from `createHash` to `hkdfSync`

### `apps/api/src/services/encryption.service.ts`
- Replaced `createHmac('sha256', 'byok-key-derivation')` with `hkdfSync('sha256', secret, 'nyx-salt', 'nyx-byok-encryption', 32)` in `deriveKey()`
- Import changed from `createHmac` to `hkdfSync`

## Notes
- HKDF provides a proper key derivation function with salt and context-specific info parameters
- The `info` parameter differs between the two files (`nyx-integration-encryption` vs `nyx-byok-encryption`) to produce domain-separated keys
- `hkdfSync` is built into Node.js `crypto` module — no new dependencies required
- **Breaking change**: Existing encrypted data will not be decryptable with the new key derivation. A migration strategy is needed for any persisted encrypted values.
- All existing tests pass (1047 API tests, 53 MCP tests, plus web/cli/shared tests)
