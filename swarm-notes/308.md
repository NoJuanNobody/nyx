# Ticket #308 — CLI: Add voice and audio commands

## What was done
- Created `packages/cli/src/commands/voice.ts` with three subcommands
- Registered the command in `packages/cli/src/index.ts`

## Implementation details
- `nyx voice join --url <meeting-url>` — POSTs to `/api/voice/join` to join a meeting; auto-detects platform (zoom, google_meet, teams) from URL
- `nyx voice status <call-id>` — GETs `/api/voice/status/:sessionId` (SSE endpoint); reads the initial event for one-shot status
- `nyx voice transcript <call-id>` — GETs `/api/voice/intelligence/:sessionId` to retrieve transcript, summary, action items, and decisions
- All commands support `--format json` for machine-readable output
- Uses existing `apiRequest` and `getBaseUrl` from `lib/api.ts`
- Platform detection supports Zoom, Google Meet, and Microsoft Teams URLs

## Build verification
- `pnpm --filter @nyx/cli build` passes with no errors
