# Ticket #151: Doc Transformation and Pipeline Sync

## What was done

1. **Schema**: Added `meetingDocuments` join table to `apps/api/src/db/schema.ts` linking documents to meeting sessions with intelligence data, platform, duration, and participants.

2. **Doc Transformer Service** (`apps/api/src/services/voice/doc-transformer.service.ts`):
   - `transformToDocument()` — converts `MeetingIntelligence` into structured markdown with sections: Summary, Decisions, Action Items (checklist), Code References, Open Questions, Participants
   - `createMeetingDocument()` — persists the transformed document in draft/definition state and creates the join record
   - Graceful handling of empty sections with placeholder text

3. **Voice Document Routes** (`apps/api/src/routes/voice-documents.ts`):
   - `POST /api/voice/documents/from-meeting` — creates document from session intelligence
   - `GET /api/voice/documents/meetings?teamId=X` — lists meeting-sourced documents
   - `GET /api/voice/documents/meetings/:documentId` — gets meeting document with full intelligence data

4. **App Registration** (`apps/api/src/app.ts`): Added `voiceDocumentRoutes` with `/api/voice` prefix.

5. **Meeting Review Workflow** (`apps/api/src/services/agent/workflows.ts`): Added `meeting_review` workflow for AI-assisted review of meeting notes.

6. **Unit Tests** (`apps/api/src/services/voice/__tests__/doc-transformer.service.test.ts`): 13 tests covering markdown generation, edge cases (empty sections), and database insertion mocking.

## Dependencies

- Requires merged meeting intelligence types from ticket #150 (`@nyx/shared` MeetingIntelligence)
- Requires merged meeting intelligence service from ticket #150
- Requires Drizzle schema push for the new `meeting_documents` table
