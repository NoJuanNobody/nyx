# Ticket #244: Fix board tickets missing repo info and 404 resource error

## Changes

### 1. Added repo info to ticket API response (`apps/api/src/services/ticket.service.ts`)
- Added `extractRepoName()` helper that parses `owner/repo` from GitHub `externalUrl` (e.g., `https://github.com/owner/repo/issues/123` -> `owner/repo`) and Jira project keys from Jira URLs
- Added `extractRepoUrl()` helper that extracts the base repository/project URL
- `listByTeam()` now returns `repoName` and `repoUrl` fields alongside each ticket

### 2. Displayed repo info on Board ticket cards (`apps/web/src/pages/Board.tsx`)
- Added a repo icon + clickable repo name link below the ticket title
- Link opens the repository in a new tab
- Uses `repoUrl` when available, falls back to `externalUrl`

### 3. Updated Ticket interface (`apps/web/src/lib/api.ts`)
- Added optional `repoName` and `repoUrl` fields to the `Ticket` interface

### 4. Fixed 404 resource error (`apps/api/src/routes/tickets.ts`)
- Changed `GET /api/tickets/:id/insights` to return `null` with HTTP 200 instead of HTTP 404 when no Claude insight exists for a ticket
- Changed the catch block from 404 to 500 for actual errors
- This prevents the browser console "Failed to load resource: 404" error
