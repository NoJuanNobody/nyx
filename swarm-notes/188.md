# Ticket #188 — LaTeX deliverable support

## What was done
- Created `apps/api/src/services/export-latex.service.ts` with:
  - `markdownToLatex(markdown, theme)` — full markdown-to-LaTeX converter
  - Handles: headings (section/subsection/etc), bold/italic, inline code, fenced code blocks (lstlisting), tables (tabular), unordered/ordered lists, display math pass-through, special character escaping
  - Four themes: `ieee` (IEEEtran), `acm` (acmart sigconf), `apa` (apa7), `plain` (article)
  - `exportLatexService.toLatex(documentId, theme)` — fetches doc from DB and converts
  - `isValidTheme()` — type guard for theme validation
- Added `POST /api/documents/:id/export/latex` route in `apps/api/src/routes/export.ts`
  - Accepts `{ theme: "ieee" | "acm" | "apa" | "plain" }` in body
  - Returns `.tex` file with `application/x-tex` content type
  - Validates theme, returns 400 for invalid, 404 for missing doc

## Tests (30 passing)
- `apps/api/src/__tests__/services/export-latex.service.test.ts` — 25 unit tests for markdown conversion (headings, inline, code, tables, lists, math, themes, special chars, full doc)
- `apps/api/src/__tests__/routes/export-latex.test.ts` — 5 route tests (happy path, theme param, invalid theme, 404, filename sanitization)
