# Ticket #309 — CLI: Add video generation command

## What was done
- Created `packages/cli/src/commands/video.ts` with three subcommands
- Registered the command in `packages/cli/src/index.ts`

## Implementation details
- `nyx video generate --prompt "..." [--doc-id <id>] [--duration <s>] [--aspect-ratio <ratio>]` — POSTs to `/api/video/generate` to trigger video generation
- `nyx video list --doc-id <id>` — GETs `/api/video?documentId=X` to list generated videos in a table
- `nyx video status <video-id>` — GETs `/api/video/:id` to check generation status
- All commands support `--format json` for machine-readable output
- Uses existing `apiRequest` from `lib/api.ts` and `formatTable`/`timeAgo` from `utils/output.ts`
- API endpoints match those defined in `apps/api/src/routes/video-generation.ts`

## Build verification
- `pnpm --filter @nyx/cli build` passes with no errors
