# 241 — Consolidate sidebar navigation and remove All Documents page

## Changes

### New file
- `apps/web/src/pages/OperationsPage.tsx` — Tabbed container page with Voice, Agents, and Observability tabs. Uses `useSearchParams` so tab state is reflected in the URL (`?tab=voice|agents|observability`).

### Modified files
- `apps/web/src/components/Sidebar.tsx` — Replaced three separate nav items (Agents, Voice, Observability) with a single "Operations" entry pointing to `/operations`. Removed the "All Documents" admin nav section and the now-unused `isAdminOnAnyTeam` variable.
- `apps/web/src/App.tsx` — Added `/operations` route rendering `OperationsPage`. Added redirect routes: `/agent-map` -> `/operations?tab=agents`, `/voice` -> `/operations?tab=voice`, `/observability` -> `/operations?tab=observability`, `/admin/documents` -> `/dashboard`. Removed unused imports (`AgentMapPage`, `ObservabilityPage`, `VoicePage`, `AdminDocuments`).
