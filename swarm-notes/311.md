# Ticket #311 — CLI: Add admin commands for super-admin operations

## What was done
- Created `packages/cli/src/commands/admin.ts` with three subcommands:
  - `nyx admin teams` — lists all teams via `GET /api/admin/teams`
  - `nyx admin users` — lists all users via `GET /api/admin/users`
  - `nyx admin stats` — shows platform statistics via `GET /api/admin/stats`
- Registered `registerAdminCommand` in `packages/cli/src/index.ts`
- All commands support `--format json|table` following existing CLI patterns

## API endpoints assumed
The existing API (`apps/api/src/routes/admin.ts`) only has `GET /api/admin/documents`.
The CLI expects these additional endpoints to be added:
- `GET /api/admin/teams` — returns `AdminTeam[]`
- `GET /api/admin/users` — returns `AdminUser[]`
- `GET /api/admin/stats` — returns `{ totalTeams, totalUsers, totalDocuments, ... }`

These API endpoints are not yet implemented and will need a separate ticket or inclusion in this one.

## Build verification
`pnpm --filter @nyx/cli build` passes successfully.
