# Ticket #295 - CLI: Add templates and marketplace commands

## Changes

- Created `packages/cli/src/commands/templates.ts` with two command groups:
  - `nyx templates list|get|create` - manage document templates
  - `nyx marketplace list|get|use` - browse and use marketplace templates
- Registered both command groups in `packages/cli/src/index.ts`

## Commands Added

| Command | API Endpoint | Description |
|---------|-------------|-------------|
| `nyx templates list` | GET `/api/templates?teamId=...` | List team templates (table) |
| `nyx templates get <id>` | GET `/api/templates/:id` | Get template details |
| `nyx templates create --name --description --content --stage` | POST `/api/templates` | Create a template |
| `nyx marketplace list` | GET `/api/marketplace` | List marketplace listings (table) |
| `nyx marketplace get <id>` | GET `/api/marketplace/:id` | Get listing details |
| `nyx marketplace use <listing-id>` | POST `/api/documents/from-template` | Create doc from listing |
