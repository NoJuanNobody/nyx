# Ticket #136 — Bulk Document Operations CLI Commands

## What was built

### CLI (`packages/cli/`)

- **`src/commands/bulk.ts`** — Three new subcommands under `nyx bulk`:
  - `bulk export --team-id <id> [--export-format markdown|pdf] [--stage <stage>] [--output-dir <dir>]` — Lists docs via GET /api/documents, downloads each via the export endpoint, writes files to disk. Prints progress to stderr.
  - `bulk status --team-id <id> --status <draft|published|archived> [--stage <stage>]` — Lists docs and bulk-updates each document's status via PUT /api/documents/:id.
  - `bulk sync --team-id <id>` — Calls POST /api/tickets/sync-all to sync all ticket statuses for a team.
  - All subcommands support `--format json|table` for summary output.

- **`src/client.ts`** — Added `getRaw(path)` method to NyxClient that returns the raw `Response` object (no `.json()` call) for binary/text export endpoints.

- **`src/index.ts`** — Added import and registration in sentinel blocks.

- **`src/__tests__/bulk.test.ts`** — 9 tests covering:
  - Command/subcommand registration
  - Markdown and PDF export flows
  - Stage filtering on export and status commands
  - Empty document list edge cases
  - Bulk status update with correct PUT calls
  - Sync endpoint invocation and result output

## Design decisions

- Used `--export-format` (not `--format`) for the file format flag to avoid collision with the output display format flag (`--format json|table`).
- Export writes progress to stderr so stdout remains clean JSON/table for piping.
- `sanitizeFilename()` strips non-alphanumeric characters from document titles for safe filesystem writes.
