# Ticket #177: Add onboarding resources: tutorial, help documentation, and examples

## What changed

Added a new "Getting Started" page with three tabbed sections:

1. **Tutorial** — A 5-step interactive walkthrough that guides new users through connecting a repo, creating a spec, exploring the lifecycle, generating tickets, and monitoring drift. Each step has a completion checkbox and progress bar.

2. **Help & FAQ** — An accordion-style FAQ covering 6 common questions (what is Nyx, drift detection, non-technical users, AI agent integration, exports, and team access).

3. **Examples** — Three practical spec examples (authentication flow, REST API design, dashboard UI) with tags and formatted spec snippets showing real-world usage patterns.

## Files modified

- `apps/web/src/pages/GettingStarted.tsx` — New page component (tutorial, help, examples tabs)
- `apps/web/src/App.tsx` — Added route `/getting-started`
- `apps/web/src/components/Sidebar.tsx` — Added "Getting Started" nav link in utility nav section (above Settings)
- `apps/web/src/__tests__/components/GettingStarted.test.tsx` — 14 unit tests covering all tabs, step completion, FAQ expand/collapse, examples rendering

## Assumptions

- Tutorial step completion is local state only (not persisted to backend). Persisting to user preferences would be a follow-up.
- The "Getting Started" link is placed in the utility nav section of the sidebar (alongside Settings and Feedback) rather than in the primary nav, since it's a resource/help page.
- Example specs are static content. A future enhancement could let users create documents from examples.

## Governance conflicts

None.

- Consider showing a "Getting Started" banner/prompt on the Dashboard for brand-new users
