# Ticket #134 — AI Governance Runtime for the Nyx CLI

## What was built

### Backend — Governance Service
- **Service**: `apps/api/src/services/governance.service.ts`
  - `validateAction()` — validates actions against governance rules from `.agentpolicy/`
    - Publish action: calls `aiService.analyzeSpecQuality`, blocks if score < 7
    - Edit/create actions: scans content for secret patterns (API keys, tokens, JWTs, private keys, AWS keys, GitHub PATs, Slack tokens)
    - Delete actions: blocked by default (requires admin-level authorization)
    - Always returns principle-violation warnings from constitution.json
  - `getRules()` — reads and returns parsed `.agentpolicy/constitution.json` and `.agentpolicy/governance.json`
  - `detectSecrets()` — exported for testing; 8 regex patterns for common secret formats

### Backend — Governance Routes
- **Routes**: `apps/api/src/routes/governance.ts`
  - `POST /api/governance/validate` — accepts `{ action, documentId?, teamId, content?, stage? }`, returns `{ allowed, violations, warnings }`
  - `GET /api/governance/rules` — returns parsed governance rules for CLI agent self-checking
- **Registered** in `apps/api/src/app.ts`

### Backend Test
- **Test**: `apps/api/src/__tests__/services/governance.service.test.ts` — 15 tests covering:
  - Secret detection (API keys, AWS keys, GitHub PATs, JWTs, private keys, Slack tokens, clean content)
  - Quality gating for publish actions (blocks < 7, allows >= 7, passes stage param)
  - Secret blocking on edit/create actions
  - Delete action blocking
  - Graceful handling when AI service unavailable
  - Publish without content (no quality check)
  - getRules returning both policy files

### CLI Package
- **New package**: `packages/cli/` — `@nyx/cli` with Commander.js
  - `packages/cli/src/index.ts` — entry point with sentinel blocks for command registration
  - `packages/cli/src/commands/governance.ts` — three subcommands:
    - `nyx governance validate --action <action> --team-id <id> [--doc-id] [--content] [--stage] [--format json|table]`
    - `nyx governance rules [--format json|table]`
    - `nyx governance check-file <file> [--format json|table]` — local-only secret scan, no API call
  - All commands exit with code 1 on violations/errors

### CLI Test
- **Test**: `packages/cli/src/__tests__/governance.test.ts` — 9 tests covering:
  - API call with correct payload for validate
  - Exit code 1 on disallowed actions
  - Optional parameter forwarding
  - Table format output with violations and warnings
  - API error handling
  - Rules fetching
  - File secret detection (violations and clean)
  - Missing file error handling
