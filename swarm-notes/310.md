# Ticket #310 — CLI: Add feature request commands

## What was done
- Created `packages/cli/src/commands/features.ts` with three subcommands:
  - `nyx features list` — lists feature requests in a table (supports `--status`, `--sort`, `--format`)
  - `nyx features submit --title "..." --description "..."` — submits a new feature request
  - `nyx features vote <id>` — toggles upvote on a feature request
- Registered `registerFeaturesCommand` in `packages/cli/src/index.ts`
- Endpoints mapped from `apps/api/src/routes/feature-requests.ts`:
  - `GET /api/feature-requests` (list)
  - `POST /api/feature-requests` (submit)
  - `POST /api/feature-requests/:id/upvote` (vote toggle)

## Build verification
- `pnpm --filter @nyx/cli build` passes with no errors.
