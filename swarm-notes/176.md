# Ticket #176: Add one-click generation for all documentation

## What changed

Added a "Generate All" feature that allows users to trigger AI-powered content generation for all documents in their project with a single click.

## Files modified

- `apps/api/src/routes/ai.ts` — Added `POST /api/ai/generate-all` endpoint that fetches all non-archived documents for a team, runs AI generation on each, updates document content, and returns a summary with success/failure counts.
- `apps/api/src/__tests__/routes/ai.test.ts` — Added 4 tests for the new endpoint: validation (missing teamId), empty docs, successful batch generation, partial failure handling, and archived document filtering. Also added db/schema and drizzle-orm mocks needed by the new route.
- `apps/web/src/lib/api.ts` — Added `generateAllDocuments(teamId)` API function and `GenerateAllResponse`/`GenerateAllResult` TypeScript interfaces.
- `apps/web/src/components/DocumentList.tsx` — Added "Generate All" button with loading spinner, success result banner (showing succeeded/total count), error banner, and partial failure messaging.
- `apps/web/src/__tests__/components/DocumentList.test.tsx` — New test file with 6 tests: renders button, calls API, shows success, shows partial failure, shows error, hidden when no documents.

## Assumptions

- "Generate all documentation" means using each document's title as a prompt to generate/regenerate AI content for all non-archived documents in the team.
- Documents are processed sequentially to avoid overwhelming the AI provider with concurrent requests.
- Archived documents are excluded from batch generation.
- The generated content replaces existing document content (regeneration, not append).
