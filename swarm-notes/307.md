# Ticket #307 — CLI: Add health/status check command

## What was done
- Created `packages/cli/src/commands/status.ts` with `nyx status` command
- Registered the command in `packages/cli/src/index.ts`

## Implementation details
- `nyx status` checks API health via unauthenticated `/health` endpoint
- Fetches team info from `/api/teams` using `NyxClient` (authenticated)
- Fetches agent session count from `/api/agent/sessions`
- Reads API URL from `~/.nyx/config.json` or `NYX_API_URL` env var
- Supports `--format json` for machine-readable output
- Pretty output matches the spec format with checkmarks and clean layout
- Exits with code 1 if API is unreachable
