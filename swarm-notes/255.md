# 255 — Add rate limiting to API endpoints

## What changed

1. Installed `@fastify/rate-limit` in `apps/api`.
2. Registered global rate limiting in `apps/api/src/app.ts` — 100 req/min per authenticated user (falls back to IP for unauthenticated requests).
3. Added stricter per-route limits on expensive endpoints:
   - **AI endpoints** (`routes/ai.ts`): 20 req/min on all POST handlers (analyze, detect-drift, generate-document, edit-document, generate-ticket, jsx-preview, jsx-preview/refine, generate-news-article, seed-next-stage).
   - **Batch AI** (`routes/ai.ts` generate-all): 2 req/min.
   - **Audio** (`routes/audio.ts`): 5 req/min on audio upload and transcript endpoints.
   - **Video generation** (`routes/video-generation.ts`): 5 req/min on generate and batch-download.
   - **Podcast** (`routes/podcast.ts`): 5 req/min on generate, audio, and radio-show endpoints.

## Auth note

The only auth route (`GET /api/auth/me`) is a lightweight read — no per-route limit added; the global 100/min default covers it.

## Rate limit headers

`@fastify/rate-limit` automatically adds `X-RateLimit-Limit`, `X-RateLimit-Remaining`, and `X-RateLimit-Reset` headers and returns 429 when the limit is exceeded.
