# Ticket #317 -- CLI: support text search for documents instead of just IDs

## Changes

1. **`packages/cli/src/client.ts`** -- Added `resolveDocId()` helper function that:
   - Accepts a string input, a `NyxClient`, and a `teamId`
   - Returns the input unchanged if it matches UUID format
   - Otherwise fetches all team documents and matches by case-insensitive title substring
   - Throws clear errors for zero matches or multiple matches (listing candidates)

2. **`packages/cli/src/commands/docs.ts`** -- Updated the `read` subcommand:
   - Renamed argument from `<id>` to `<idOrTitle>` for clarity
   - Added `--team-id` option (needed when resolving by title)
   - Pipes the input through `resolveDocId` before fetching the document

## Testing

- `pnpm --filter @nyx/cli build` passes with zero errors.
