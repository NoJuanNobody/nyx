# Ticket #292 — CLI: Add document branch commands

## What was done
- Created `packages/cli/src/commands/branches.ts` with five subcommands:
  - `nyx branches list <doc-id>` — lists branches for a document (table output)
  - `nyx branches create <doc-id> --name "..." --base-version <id>` — creates a branch
  - `nyx branches diff <branch-id> --doc-id <id>` — shows branch diff (readable output)
  - `nyx branches approve <branch-id> --doc-id <id>` — approves a branch
  - `nyx branches merge <branch-id> --doc-id <id>` — merges a branch
- Registered `registerBranchesCommand` in `packages/cli/src/index.ts`

## API mapping
All endpoints are nested under `/api/documents/:documentId/branches` (from `apps/api/src/routes/branches.ts`).
The `diff`, `approve`, and `merge` subcommands require `--doc-id` since the API routes are document-scoped.

`pnpm --filter @nyx/cli build` passes with zero errors.
