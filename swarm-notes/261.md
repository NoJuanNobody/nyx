# 261 — Add Content Security Policy headers

## Changes

1. **`apps/api/package.json`** — Added `@fastify/helmet` dependency.
2. **`apps/api/src/app.ts`** — Imported and registered `@fastify/helmet` after CORS registration with CSP directives covering `default-src`, `script-src`, `style-src`, `font-src`, `connect-src`, `img-src`, and `frame-src`.
3. **`apps/web/index.html`** — Added `<meta http-equiv="Content-Security-Policy">` tag as a client-side fallback. Includes `'unsafe-inline'` for `script-src` to support the existing inline theme-detection script.
4. **`vercel.json`** — Added `headers` array with `Content-Security-Policy`, `X-Frame-Options: DENY`, and `X-Content-Type-Options: nosniff` for the Vercel deployment.

## Notes

- The `index.html` and `vercel.json` CSP policies include `'unsafe-inline'` for `script-src` because there is an existing inline `<script>` block for theme detection. The API helmet config does not need this since it only serves JSON.
- The `connect-src` in the frontend policies uses `https://*.up.railway.app/` to allow the staging API proxy, while the API helmet policy uses `https://api.anthropic.com/` for server-side AI calls.
- All 1047 existing tests pass.
