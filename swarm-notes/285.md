# Ticket #285 - Add pgvector to Postgres & doc_chunks schema

## Changes

1. **`apps/api/src/db/schema.ts`** - Added `docChunks` table with:
   - `id` (UUID, PK)
   - `docId` (FK -> documents, cascade delete)
   - `orgId` (FK -> teams, cascade delete)
   - `content` (text, not null)
   - `embedding` (vector(1536), nullable)
   - `version` (integer, not null)
   - `chunkIndex` (integer, not null)
   - `createdAt` (timestamptz)
   - HNSW index on `embedding` with `vector_cosine_ops`
   - Composite index on `(docId, version)`
   - Used Drizzle's built-in `vector` column type (available in drizzle-orm 0.38)

2. **`apps/api/src/db/index.ts`** - Added `CREATE EXTENSION IF NOT EXISTS vector` execution on startup.

3. **`.github/workflows/ci.yml`** - Changed all `postgres:16` service images to `pgvector/pgvector:pg16` (3 occurrences: test, smoke, e2e jobs).

## Type check

All pre-existing `@nyx/shared` module errors remain; no new errors introduced by this change.
