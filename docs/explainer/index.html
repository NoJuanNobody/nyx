What is Nyx and what is it like to use?

Long image

A

Answer

Nyx is a web app that keeps product docs and code in step. You write an idea as a document and AI carries it through five lifecycle stages. Approved changes become GitHub or Jira tickets, and code pushes are checked for drift.

  1. You start from plain words: Intake turns a rough idea into a spec with a user story, acceptance criteria and open questions.1
  2. Each document can carry a stage, and one click drafts the next-stage document from the current one.2
  3. Edits to a spec become a change proposal of suggested tickets that you approve and push.3
  4. Pushes to a connected GitHub repo trigger an AI drift check that logs a drift score on each affected document's timeline.4

Applies toRead from the nyx repo at commit f78c601 (Oct 2026). Working code: React web app, Fastify API, Postgres, CLI and MCP server. Self-hosting needs Postgres, an Anthropic key and Clerk keys.

Diagram structure

  • GitHub or Jira issues tickets
  • Code push push
  • Drift check drift
  • Doc timeline timeline
  • doc → next · seed
  • drift → timeline · score
  • idea → intake · paste
  • intake → doc · save
  • next → proposal · edits
  • proposal → tickets · approve, push
  • push → drift · webhook
  • tickets → push · build
  1. Rough idea ↗

    Type the idea in plain words on the Intake page.

  2. Intake spec ↗

    AI returns a title, user story, acceptance criteria, edge cases and open questions. Low confidence asks you clarifying questions first.

  3. Stage document ↗

    Save it as a document in the editor and give it a stage, such as Definition.

  4. Next-stage draft ↗

    Seed the next stage: AI writes, for example, the Architecture doc from the Definition doc.

  5. Change proposal ↗

    New versions of a doc are grouped by AI into suggested tickets. You untick the ones you do not want.

  6. GitHub or Jira issues ↗

    Approve and push; each ticket is created in the connected tracker and linked back to the doc.

  7. Drift check ↗

    When code is pushed, Nyx compares each team doc with the push and logs a drift score.

What should I know before relying on it?

Limits found in the code

The push-triggered drift check sends the list of changed file paths, not the file contents, as the code side of the comparison.4 Pushing a whole change proposal creates GitHub issues only; Jira is available when you create a single ticket from a document.9 Every AI feature needs an Anthropic API key, and sign-in needs Clerk.10
