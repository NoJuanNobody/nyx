# SyncDocs PR Template

Use this template when opening the pull request after all swarm branches are merged.

---

## PR Title

```
[Swarm] <short summary of the batch> (#<first-ticket> – #<last-ticket>)
```

Example: `[Swarm] Auth + Export improvements (SD-101 – SD-104)`

---

## PR Body Template

```markdown
## 🤖 Swarm PR

This PR was generated by a parallel agent swarm. Each ticket was implemented in an isolated git worktree and merged sequentially.

---

## Tickets implemented

| Ticket | Title | Branch | Status |
|--------|-------|--------|--------|
| SD-101 | Add rate limiting to /api/export | swarm/SD-101 | ✅ merged |
| SD-102 | Fix session token expiry bug | swarm/SD-102 | ✅ merged |
| SD-103 | Update user schema for roles | swarm/SD-103 | ✅ merged |

---

## Test results

```
$TEST_COMMAND output (trimmed to last 30 lines)
```

All tests: **PASS** / **FAIL** (mark appropriately)

## Implementation notes

<aggregated content from swarm-notes/*.md>

---

## Follow-up items

<aggregated follow-up items across all agents>

---

## How this was generated

Parallel swarm via `syncdocs-swarm` Claude Code skill.
Batches: $BATCH_SUMMARY
Merge order: $MERGE_ORDER
```

---

## GitHub CLI command

```bash
gh pr create \
  --title "[Swarm] <summary>" \
  --body-file /tmp/swarm-pr-body.md \
  --base main \
  --label "swarm,automated"
```

Write the rendered body to `/tmp/swarm-pr-body.md` before running.
